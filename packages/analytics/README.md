# @optz/analytics

Optional OPTZ module. No default browser initialization or static-request work.

See the [complete guide](../../docs/ANALYTICS.md) for setup, APIs, security boundaries and examples.
Source exports live in `src/`; checks are `bun test` and `bun run check` from this package.

Use a `workspace:*` dependency in this repository and run `bun install` at the root.
Packages are source artifacts here; publishing is a separate release operation.
